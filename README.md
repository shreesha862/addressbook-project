# Address Book Application

A console-based application written in C to store, manage, search, and update contact details including names, phone numbers, and email addresses.

## Features
- **Add Contact:** Create new contacts with a name, phone number, and email address.
- **Search Contact:** Look up existing contacts by name, phone number, or email address.
- **Edit Contact:** Update contact details by searching via name, phone number, or email address.
- **Delete Contact:** Remove contacts from the address book by name, phone number, or email address.
- **List All Contacts:** Display all saved contacts in a clean, organized format.
- **Save & Exit:** Persist all contact records to a file so data is saved between sessions.

## Tech Stack
- **Language:** C
- **Concepts:** File Operations, Structures, Arrays, Input Parsing, Standard I/O

## Menu Options
1. Add Contact
2. Search Contact
3. Edit Contact
4. Delete Contact
